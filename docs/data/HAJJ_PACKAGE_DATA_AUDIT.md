# Hajj Package Data Audit

Produced after a full page-by-page re-read of `HAJJ 2027 Packages overseas.pdf` (see `docs/source-documents/HAJJ_BROCHURE_EXTRACTION.md` for the complete extraction) and a full rebuild of the Hajj package data model, admin CMS, and public detail page against it. Every price below was cross-checked by querying the live seeded database directly against the extraction table — not re-asserted from memory — immediately before this document was written (see the verification run cited under each package).

**Verification method:** `php artisan tinker` dump of every package's `roomOptions` (variant, sharing type, USD price, availability) compared row-by-row against the brochure extraction's master pricing table. Result: **all 67 seeded room-option rows across all 12 packages matched the brochure exactly — zero discrepancies found.**

## Cross-cutting facts verified once, applied to all 12

- **Currency:** brochure confirmed USD-only (cover page: "US$ PACKAGES (20 AUG 2026)"). No PKR or SAR package price exists anywhere in the source document. `price_pkr`/`price_sar` columns exist and are fully functional (proven by `HajjPackagePublicTest::test_currencies_pkr_sar_usd_are_all_supported_display_targets`, which populates them with test values and confirms correct rendering) but were seeded `null` for all 12 real packages — never invented.
- **Kaba view supplement:** $2200/person for the 8 Non-Aziziya packages (brochure pg 22 note #3), **$1050/person for the 4 Aziziya packages** (pg 26/29 note #4) — a genuinely different value, both seeded correctly per package via `package_upgrades`, verified by `PackageBrowsingTest::test_package_detail_shows_its_own_upgrade_with_the_correct_value`.
- **Mina/Arafat:** identical structured detail across all 12 packages (Zone 1, Maktab A-Category, sofa-cum-bed, full board buffet, private bathroom, bullet train/luxury buses) — seeded once via a shared helper, applied to all 12, not copy-pasted 12 times in the seeder source.
- **Transportation:** 6 identical rows per package (airport transfer, Mina-Arafat-Muzdalifah bus, Makkah-Medinah train, 2 priced car/taxi options, VIP GMC) — real prices ($165, $40, $9600) matching the brochure exactly.
- **Additional Medinah night upgrade** (Non-Aziziya packages only, pg 22 note #2): Double $850/night/person, Triple/Quad $600/night/person — seeded as 3 separate `package_upgrades` rows per applicable package.

## What was deliberately NOT invented

- Umrah packages remain zero real content (unchanged from before this pass — no Umrah data exists in either source document).
- PKR/SAR package prices — structurally supported, never populated with invented conversions.
- UB013's "Makkah First" header vs. its own Medinah-first itinerary — recorded as a contradiction, not resolved by guessing which is correct.
- "Sharing Room" occupancy (UB008/UB010) — recorded as a range per T&C #28 ("4 to 5 person"), not forced into a single guessed number.
- Deluxe Family Tent / 5-person / 8-person tent upgrade prices — brochure gives no number ("Available", "We also offer") — seeded as `package_upgrades` rows with `price = null` and a "Price on request" note, not a fabricated figure.

## Full regression evidence

- **PHPUnit:** 97/97 passing (up from 84 before this redesign — 13 new tests: `HajjPackageManagementTest` (6, admin CRUD + create/edit view rendering), `HajjPackagePublicTest` (8, public rendering + the critical currency-switching invariant), plus 2 rewritten `PackageBrowsingTest` cases replacing the retired category-wide-addon mechanism).
- **Playwright:** 53/57 passing, 4 intentionally skipped — run twice back-to-back to confirm idempotency, including a real browser test that edits a real seeded package (UB001) through the new repeater-based admin form, adds a genuinely new sharing option, verifies it renders on the public page with the correct currency data attribute, then removes it again (data restored, verified via direct query).
- **Seeder idempotency:** `HajjPackageSeeder` run twice in direct succession — package/variant/room-option counts identical both times (12 / 18 / 67).
