**Actions performed (in order):**

- Your name appears at the top right.

**Important notes:**

- This training builds one complete Hajj package, based on the approved brochure package UB015, from the first field to the published page.
- The video was recorded in a separate training copy of the admin. Nothing in it changed the real website.

**Expected result:** You are signed in and see the dashboard.

## 2. Understanding the Dashboard

*Getting Started · Beginner · about 3 min to do · video 0:45*

**Title card:** Chapter 2 — Understanding the Dashboard — What the numbers, cards and shortcuts on the dashboard mean.

**Objective:** Read the dashboard and know what needs attention.

**Actions performed (in order):**

1. On a first visit, the welcome panel offers a short guided tour. "Skip for now" hides it; the tour stays available from the account menu.
2. Read the four Hajj package cards: total, published, drafts and featured. Each card opens the matching list.
3. The "Enquiries and content" cards count new enquiries, FAQs, awards and more.
4. "Needs attention" and "Unfinished drafts" appear only when something is waiting — an incomplete live package, an unanswered enquiry or a draft you started.
5. "Recent package updates" lists the packages changed most recently.
6. "Quick actions" on the right open the most common jobs.

**Why it matters:** The dashboard shows live numbers from the website, so you can see at a glance whether anything is waiting for you.

**Common mistakes:**

- Ignoring "Needs attention" — it lists live packages customers can already see.

**What the admin should check:**

- You know where "Add Hajj Package" and "Unfinished drafts" are.

**Important notes:**

- Every number is counted live from the website.

**Expected result:** You can read the dashboard and open any list from it.

## 4. Creating a New Hajj Package

*Hajj Package Creation · Beginner · about 2 min to do · video 0:36*

**Title card:** Chapter 4 — Creating a New Hajj Package — Open the package builder and understand its 14 steps, checklist and help panels.

**Objective:** Start a new Hajj package in the builder.

**Actions performed (in order):**

1. On the Hajj Packages list, press "Add Hajj Package".
2. The 14 steps are listed on the left. A green tick means a step has what it needs; the percentage shows how complete the package is.
3. Open "Need help with this step?" under any step title for a short explanation and an example.
4. The bar at the bottom has Save draft, Save & preview, Save & continue and Publish. Nothing is on the website until you publish.

**Why it matters:** The builder splits a large package into small steps so nothing is missed, and lets you stop and continue later.

**Common mistakes:**

- Waiting until the end to save — press "Save draft" whenever you stop.

**What the admin should check:**

- The builder shows "Step 1 — Basic information".

**Important notes:**

- To save typing on a similar package, use Duplicate or "From a template" instead. This training builds one from the start so every step is shown.

**Expected result:** A new, empty package is open in the builder.
