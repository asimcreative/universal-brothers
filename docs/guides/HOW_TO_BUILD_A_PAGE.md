# How to Build a Website Page — Step by Step

For Universal Brothers office staff. No technical knowledge is needed. The same help is inside the admin: open **Admin Guide** in the menu and read **Building a page from sections**, **Writing formatted text**, **Images and image descriptions**, **Saved sections**, **Search results and sharing** and **When a page says something needs fixing**. You can also press the **?** button at the top of any page screen.

---

## Before you start

- **Nothing you change reaches the website until you press Publish.** "Save draft" is always safe, even if the page is half finished.
- Have your words and photos ready. Photos should be JPG, PNG, WebP or GIF, smaller than 5 MB.
- A page is made of **sections** stacked from top to bottom: a banner, some text, a photo with text, packages, questions, an enquiry form, and so on. Each section already looks like the rest of the website.

## 1. Create the page

1. Open **Website Content → Pages** and press **New Page**.
2. Type the **page title**, for example *Hajj Preparation Guide*. The **page address** fills in by itself (*hajj-preparation-guide*). It may only use small letters, numbers and single dashes.
3. Choose a **starting layout**:
   - **Simple page**: one text section. Good for policies and terms.
   - **Information page**: a banner, text, text with a photo, and a call to action.
   - **Service page**: a banner, your services, packages, testimonials, questions and an enquiry form.
   - **Company page**: the company story with licence details, figures, awards and affiliations.
4. Press **Create draft and start building**. The page is a draft and is not on the website yet.

## 2. Fill in the sections

- Click a section's name to open it. **Open all** and **Close all** help on long pages.
- Every field has a plain label. Fields marked with a red **\*** must be filled in before publishing.
- **Buttons** need both the button text and the link. A link is either a page on this website starting with a slash (*/contact*) or a full address starting with *https://*. If a link is wrong, the message tells you how to fix it.
- **Videos**: open the video on YouTube or Vimeo, copy the address from the browser bar and paste it.

## 3. Write formatted text

Text sections use the **text editor**. It works like a simple word processor:

| To… | Do this |
|---|---|
| Make words bold, italic or underlined | Select them and press **B**, **I** or **U** (or Ctrl+B / Ctrl+I / Ctrl+U) |
| Add a heading inside the text | Choose it from **Text style** |
| Make a list | Press **Bulleted list** or **Numbered list** |
| Add a link | Select the words, press **Add or edit link** (Ctrl+K), paste the address, press **Add link** |
| Add a photo or a video inside the text | Press **Insert image** or **Insert YouTube or Vimeo video** |
| Add a table | Press **Insert table**. Extra buttons for rows and columns appear while you are inside the table. |
| Remove formatting pasted from Word or a website | Select the text and press **Clear formatting** |
| Write with more room | Press **Full screen**. Press Escape to return. |

The counter under the editor shows words and characters. Keyboard users can press **Alt+F10** to reach the formatting buttons, and **Escape** to go back to the text.

## 4. Add photos with descriptions

1. In a photo field, press **Choose image**.
2. Pick a photo from the **Library**, or open **Upload a new image** and choose a file from your computer.
3. Fill in **Image description**. It is one sentence for people who cannot see the photo, and it also helps Google. Example: *Pilgrims on the plain of Arafat*.
4. Press **Upload image** (or **Use this image**). The photo appears in the section with its description.

A photo that shows information needs a description before the page can be published. Background photos in banners are decorative and do not.

## 5. Arrange the sections

| To… | Do this |
|---|---|
| Add a section | Press **Add a section** at the bottom, or **Add a section below** in a section's **⋮** menu. Search or browse, then click the kind you want. |
| Move a section | Drag it by the dotted grip on its left, **or** press its up / down arrow buttons, **or** click the grip and press the ↑ ↓ keys |
| Copy a section | **⋮** → **Duplicate**. The copy appears just below. |
| Hide a section for now | Press the **eye** button. Hidden sections stay in the page but visitors do not see them. |
| Remove a section | **⋮** → **Delete section**, then confirm |
| Change your mind | Press **Undo** at the bottom (or in the message that appears). Undo works until you leave the page. |

## 6. Title, address, search and sharing

- **Title & address** tab: the page title, the page address, and an optional banner photo. Avoid changing the address of a page that is already live, because links people saved would stop working.
- **Search & sharing** tab: the title and description Google shows, a preview of the Google result, an optional focus phrase with tips, and the title, description and image used when the page is shared on WhatsApp or Facebook. Leave anything empty that you are not sure about; sensible defaults are used.

## 7. Preview, publish or schedule

1. Press **Save draft** whenever you stop.
2. Press **Save & preview** to see the page exactly as visitors will. Switch between **Desktop**, **Tablet** and **Phone**.
3. Press **Publish**. If something needs fixing, the page is **not** published but your work **is** saved. A red box at the top lists each problem, for example *"Section 2 (Page banner): heading is empty"*. Click a problem to jump to the field, fix it, and press **Publish** again.
4. To publish later, open the arrow beside **Publish** → **Schedule for later…**, choose the date and time, and press **Schedule**. If the page is already live, it is taken off the website until that time.

## 8. After publishing

- To change a live page, edit it and publish again. Visitors keep seeing the old version until you do.
- **More** → **Discard unpublished changes** throws away your draft and goes back to what is live.
- **More** → **Unpublish** takes the page off the website and keeps its content as a draft.
- The **History** tab keeps a copy each time the page is published. **Restore as draft** brings an earlier version back for you to check and publish again.
- **More** → **Duplicate page** (or **Duplicate** in the Pages list) makes a draft copy. Change its title and address before publishing it.

## 9. Reuse a section on other pages

1. In a section's **⋮** menu, choose **Save for reuse on other pages**. Give it a name and a group, and press **Save section**.
2. On any page, press **Add a section**, open the **Saved sections** tab and press **Insert a copy**. The copy belongs to that page; changing it does not affect other pages.
3. A super admin can instead press **Insert linked**. That page then always shows the saved section's latest content. Only a super admin can change a saved section that pages link to, because every linked page changes at once.

Manage saved sections under **Website Content → Saved Sections**: edit, preview, duplicate, archive, restore or delete them.

## Common problems

| Message or problem | What to do |
|---|---|
| "Your changes are saved as a draft, but the page was not published yet." | Fix each item in the red box, then press Publish again. |
| "… heading is empty" / "… is empty" | Fill in the field, or delete the section if you do not need it. |
| "… is not a link the website can open" | Start a page on this site with a slash (*/contact*) or a full address with *https://*. |
| "… describe … for people who cannot see it" | Add one sentence in the photo's description box. |
| "Another page already uses this address" | Choose a different page address. |
| "Every section on this page is hidden" | Press the eye button on at least one section. |
| "This image is too large" | Choose a photo smaller than 5 MB. Photos shared from a phone are usually smaller. |
| I changed a saved section but a page did not change | That page has a copy, not a link. Edit the section on the page itself. |
| The Save button is greyed out on a saved section | Pages link to it, so only a super admin can change it. Duplicate it and change your copy. |
| Where did my About Us page go? | It is still under Pages. The first time you edit it, its current text is turned into sections for you. The live page stays the same until you publish. |
